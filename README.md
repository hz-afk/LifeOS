# LifeOS SaaS

This repository contains the UI designs for the LifeOS SaaS application based on the Product Requirements Document (PRD).

## Project Designs

The designs for the core modules (Tasks, Finances, Life Goals, and Universal Dashboard) have been generated and are available to view and interact with in the Stitch project. The HTML code for these pages has also been downloaded and organized in the `src/pages` directory.

You can view the project and all its screens here:
[LifeOS SaaS Stitch Project](https://design.google.com/stitch/project/9582259309604627817)

### Local Files
The downloaded HTML files for each module can be found in `src/pages`:
*   `src/pages/universal_dashboard.html`: The main dashboard page.
*   `src/pages/finances_dashboard.html`: The finances page.
*   `src/pages/life_goals_dashboard.html`: The life goals and planning page.
*   `src/pages/tasks_dashboard.html`: The tasks and productivity page.

### Modules Designed:
*   **Modul 4: Sistem & Pengalaman Pengguna (Universal Dashboard)**: A central hub showing daily tasks, habit streaks, and a high-level financial overview.
*   **Modul 2: Manajemen Keuangan (Finances)**: Detailed breakdown including Net Worth, 50/30/20 Budgeting visualization, Recent Transactions, and Financial Goals (Sinking Funds).
*   **Modul 3: Perencanaan Kehidupan (Life Planning & Goals)**: Features a visual Vision Board, a detailed breakdown of a major goal (e.g., 'Buy a House'), and a Journal/Reflection area.
*   **Modul 1: Manajemen Tugas & Produktivitas (Tasks)**: Includes a Smart Inbox categorized by life domain, a Habit Tracker, and a large Calendar view.

All designs adhere to the "Futuristic Minimalism" design system.
